# 生成代码与中文注释

仅约束本次新生成的手写代码，不追溯补写已有代码。默认中文、等级 3；新项目读取 `comment_level`，已有项目以项目配置或用户要求为准：

1. 无解释性注释。
2. 说明页面或文件用途。
3. 再说明业务自定义方法、Model 用途和复杂实现思路。
4. 再说明重要属性、控制流、边界和错误处理。

共同限制：

- 不注释系统、继承、生命周期、delegate 或 data source 方法。
- 不生成文件名、项目、时间、作者、Git 等文件头。
- 不使用“类型职责”“方法职责”“Model 职责”等标签。
- 不复述代码；只解释业务目的、约束、取舍和非显然原因。
