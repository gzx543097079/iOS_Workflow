# 数据打点 Checklist

- [ ] 每个事件的名称、业务含义和指标口径与数据埋点文档一致。
- [ ] 打点位置与事件含义匹配：曝光在真实可见时、点击在用户操作时、结果在成功或失败确认后上报。
- [ ] 页面、按钮、订阅项和购买流程的关键节点完整，没有缺失、提前或错位上报。
- [ ] 参数名称、类型、枚举值和必填性与文档一致；订阅事件参数来自当前实际交易。
- [ ] 页面重复出现、连续点击、请求重试、前后台切换和交易回调不会导致重复或遗漏上报。
- [ ] 不包含 token、完整支付信息或未允许的个人数据，并遵循用户同意、ATT 和隐私配置。
- [ ] 已在调试日志或分析平台 DebugView 核对事件名、次数、顺序、参数和上报环境。
