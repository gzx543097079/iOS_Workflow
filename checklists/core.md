# 通用 Checklist

- [ ] 需求范围、验收条件和非目标已经确认。
- [ ] 生成测试中的 `TODO` 已替换为真实业务场景，新增或修改的分支有相应测试。
- [ ] 已运行项目最小相关的构建、测试和静态检查。
- [ ] 项目能够编译，且没有新增编译警告或静态检查错误。
- [ ] UI 改动复用了 `DesignTokens`，并检查深色模式、动态字体、本地化和可访问性；未修改 UI 时标记 `➖`。
- [ ] 配置、资源、文档和生成产物已与代码行为同步。
- [ ] 已暂存和未暂存 diff 只包含本次需求相关内容，未包含密钥、个人数据、构建产物或调试代码。
- [ ] 所有适用项均已确认；未受影响或不适用项已标记为 `➖` 并说明原因。
