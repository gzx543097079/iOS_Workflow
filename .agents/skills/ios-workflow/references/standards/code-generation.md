# 生成代码与中文注释

仅约束本次新生成的手写代码，不追溯补写已有代码。默认中文、等级 3；新项目读取 `comment_level`，已有项目以项目配置或用户要求为准：

1. 无解释性注释。
2. 说明页面或文件用途。
3. 再说明业务自定义方法、Model 用途和复杂实现思路。
4. 再说明重要属性、控制流、边界和错误处理。

共同限制：

- 不注释系统、继承、生命周期、delegate 或 data source 方法。
- 不生成文件名、项目、时间、作者、Git 等文件头。
- 不使用“类型职责”“方法职责”“Model 职责”等标签。
- 不复述代码；只解释业务目的、约束、取舍和非显然原因。
- 新增用户可见文案必须使用本地化键，不在 Swift、Objective-C 或界面声明中硬编码。
- 新项目以 `assets/config/defaults.jsonc` 的 `supported_localizations` 为语言范围；已有项目以自身配置为准。每个新增本地化键必须同步提供全部已配置语言的语义正确译文，不得用默认语言、键名或占位文本代替翻译。
- 新增或移除配置语言时同步更新全部本地化键；专有名词、商标、代码和无需翻译的内容可以保持一致，但必须显式写入对应语言资源。
