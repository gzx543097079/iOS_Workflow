# 项目生成检查

仅在新建项目或 diff 影响项目生成器、默认配置、DesignTokens 生成时执行。

- 配置在写入前完成校验，非法组合和非空目标目录会停止。
- 语言、UI、架构、导航、暗黑模式、手动外观切换、本地化、注释、测试、签名和设备选项已映射到生成结果。
- Swift/UIKit、Swift/SwiftUI、Objective-C/UIKit 组合受支持；Objective-C/SwiftUI 被拒绝。
- 生成 API 与最低部署版本兼容，项目名不会遮蔽系统框架模块。
- DesignTokens 来自配置，生成注释符合等级且未注释系统或继承方法。
- 直接依赖只允许精确版本，工程生成后按管理器完成安装或解析。
- 单元测试、UI 测试、本地化、隐私清单等开关与实际文件和 target 一致。
- 每个用户可见文案使用本地化键，并在生成结果中覆盖 `supported_localizations` 的全部语言；不存在默认语言冒充译文或缺少语言资源的情况。
- 暗黑模式关闭时工程固定浅色；手动切换开启时生成持久化外观策略，且不存在“关闭暗黑模式同时开启手动切换”的非法组合。
- XcodeGen 生成唯一工程；相关自动化测试通过，源码或工程设置变化时完成最小编译验证。
