# 通用 Checklist

- [ ] 需求范围、验收条件和非目标明确。
- [ ] 本次声明完成范围的必需测试已落实；生成骨架及范围外 TODO 保留为待办，不冒充通过，也不阻止保存阶段进度。
- [ ] 普通提交或验收交付的最小相关构建、测试和静态检查通过；证据键未变时复用。checkpoint 则如实记录已执行、失败、阻塞及尚未验证的范围，成功证据不是保存前提。
- [ ] 本次声明完成的 UI 范围符合项目设计系统和受影响的外观、字号、本地化及可访问性要求；checkpoint 的未完成部分如实保留，未改 UI 则 `➖`。
- [ ] 配置、资源、文档和生成产物与所声明状态一致；阶段中的未完成差异没有被描述为完成。
- [ ] 修改范围在授权内，未覆盖用户文件或丢失必要记录，无密钥、个人敏感数据或不应提交的构建产物；待清理的阶段调试代码已标明，不混入正式交付。范围、隐私、用户文件和记录检查失败或未知均阻止保存。
- [ ] 所有不适用项均以 `➖` 说明原因。
