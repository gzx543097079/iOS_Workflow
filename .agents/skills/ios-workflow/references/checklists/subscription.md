# 订阅 Checklist

- [ ] App Store Connect、StoreKit 配置、服务端与客户端的订阅项、product ID 和权益映射一致。
- [ ] 月付、年付、试用、促销与恢复购买等入口匹配正确订阅项，不会购买或解锁其他权益。
- [ ] 价格、币种、计费周期、折扣与试用信息来自 StoreKit 有效商品数据，未硬编码展示价格。
- [ ] 订阅文案与实际价格、币种、周期、试用资格、自动续费和取消规则一致，本地化后仍一致。
- [ ] 用户选择、按钮文案、购买 product ID 与最终发放权益逐项匹配。
- [ ] 成功、失败、取消、pending、恢复、过期、退款和宽限期均已验证，权益状态与交易结果一致。
- [ ] 订阅页提供恢复购买、服务条款和隐私政策入口，并使用 Sandbox 或 StoreKit Configuration 验证。
